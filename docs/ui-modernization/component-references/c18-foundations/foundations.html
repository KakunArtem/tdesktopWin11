C18 Foundations: visual reference

Icons are masks recolored by palette entries. Under the material the grey ones fall to 1.3–2.7:1, so C18 raises them like C3 raises text: resting icons to 3:1, hover icons to 4.5:1 so hover stays stronger. Shapes, type sizes and durations stay Telegram's.

A. Mockup targets: icons that read on the panels

The readable mockup draws its rail, header and composer icons in the secondary text color, so they read like the text next to them. Crops of the C7 captures at 100%. The mockup's line icons are a style; Telegram keeps its own icon set.

B. In the main window: Navigation, Conversation, Composer and Popup roles

The rail, the lock and search cancel in the chats list, the chat header, the reply bar's cancel, the composer and the emoji panel's tabs. One icon in each area is hovered: the call button, the lock and the attach button, on the soft hover.

C. In a box: title buttons and small close icons in the Popup role

Box and info layer title buttons use boxTitleCloseFg; the session list's terminate cross uses smallCloseIconFg, the faintest grey in the palette.

D. Icon entries raised while material is active (Task 1)

Worst contrast is over the strictest floor of the entry's roles (Navigation 0.78 day, Conversation 0.81 night for the three-role rows; Composer 0.96; Popup 0.97) on a black and a white backdrop. Values come from C3's compute-fills.py.

Found while checking the rail: labels belong to C9

C4 paints the rail with the Navigation role, so in the day theme it turns light while its entries stay made for Telegram's dark sidebar (sideBarBg #293a4c, selected sideBarBgActive #17212b). C18 raises the rail icons. The labels and the selected fill are recorded as an open decision for C9.
