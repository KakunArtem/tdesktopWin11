C4 Surface roles: visual reference

Telegram's current layout with each background painted through its role. Fills are the C3 values for the default day and night themes; the Soft Panels layout arrives with C7.

A. Which role paints where

Rail and chats list share the Navigation fill, the header uses Conversation, the composer and reply strip use Composer. The chat wallpaper, bubbles and title bar stay opaque in this phase.

Navigation: Dialogs::Widget, InnerWidget, FiltersMenu::_outer Conversation: TopBarWidget Composer: ComposeControls, HistoryWidget::drawField Window: MainWindow body, visible only in gaps Opaque: wallpaper (C11), title bar (C8)

B. Painting the same fill again: Source replaces, SourceOver accumulates

A chats list row repainted on every hover. PaintFill uses CompositionMode_Source, so the fifth repaint looks like the first. Blending with SourceOver piles each repaint on the last, until the row is opaque.
