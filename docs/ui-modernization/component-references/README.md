# Component visual references

One visual reference per component of the
[component architecture](../architecture.md), each linked from its
[plan](../plans/README.md). A reference isolates what one component changes,
taken from the [readable Soft Panels mockup](../explorations/README.md), and
records the values and checks to compare a native build against.

These are proposals derived from the mockup. The
[approved reference](../reference/README.md) stays unchanged.
