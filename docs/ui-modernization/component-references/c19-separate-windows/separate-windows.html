C19 Separate windows: visual reference

Separate windows stay opaque, as the user decided. The restore shell takes the material of the window it stands in for. As the user chose, Telegram's notifications and separate panels take the popup shape: radius 12 and the Popup role's 1 px border, with an opaque fill.

A. Telegram's notifications (Task 2)

320 × 80 cards at the bottom right, 7 px apart, with a 36 px Hide all bar above them. The top card is hovered and shows Reply. Today each card is a square opaque window with a 1 px windowShadowFgFallback edge; in the night theme that color equals windowBg, so the card has no edge at all.

B. Separate panels: a Mini App (Task 3)

Ui::SeparatePanel is already a rounded, shadowed window at callRadius 6 px. The popup shape raises the radius to 12. When a panel has no bottom bar, its web view must not reach into the larger corner (Task 3 Step 1).

C. Restore shell (Task 1)

While a separate chat window reopens at startup, a placeholder RpWindow fills itself with windowBg and shows a spinner. With material on, the window that replaces it has the material, so the placeholder flashes an upstream window first. The shell takes the Window role and the title painter instead.
