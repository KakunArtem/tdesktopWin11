C6 Toolkit fork: visual reference

C6 changes no pixels. It gives lib_ui and lib_base changes a home; this sheet shows the branch layout, the .gitmodules change, the upstream update and the outputs that prove each step. Fork commit names are examples from the C8 and C14 plans.

A. Where the commits live

soft-panels starts at the commit tdesktop pins today. Every tdesktop pointer update is its own commit and points at a fork commit that is already pushed.

C. Taking an upstream update (Task 3)

After an upstream tdesktop merge moves the pin from U0 to U1, the fork commits are rebased onto U1 under a new branch name. soft-panels is never force-pushed and stays where it was.
