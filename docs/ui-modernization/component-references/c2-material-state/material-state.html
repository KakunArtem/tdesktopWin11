C2 Material state: visual reference

The "Use window transparency" setting, its restart prompt, the startup decision and how the window looks in each state. Settings and boxes keep Telegram's current style; C15 restyles them later.

A. Settings > Advanced > Window title bar

The new checkbox (outlined) follows "Use system window frame" and is shown only on Windows build 22621 or later.

B. Restart prompt after a change

The box BuildANGLEOption already uses: lng_settings_need_restart, Cancel, lng_settings_restart_now.

C. Startup decision and live state

C2 owns the state; the fills that make "Active false" solid come from C3. A refusal at startup is not undone by a later live change: it needs a restart.
