# Chat List and Search Implementation Plan (C10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the chats list to the exploration: rounded row highlights inset from the panel edges, a quiet hover, a rounded search pill on the material, and readable names, previews, times and badges, with every list behavior kept.

**Architecture:** Row geometry and heights stay Telegram's (`dialogsRowHeight` 62 px, avatars 46 px). Highlights become rounded pills drawn inside the existing row rectangle, so no layout, scrolling or hit-testing code changes. The search field gets a parallel style with a transparent field background, and `Dialogs::Widget` paints a Bar-role pill behind it. Everything is selected by `SoftPanels()`.

**Tech Stack:** C++20, Qt 6.11 Widgets, `dialogs/dialogs.style`, `Ui::RowPainter` (`dialogs/ui/dialogs_layout.*`).

**Spec:** [architecture.md, Element styling](../architecture.md#element-styling-c9c15); exploration CSS `.search`, `.chat-list`, `.chat-row`, `.unread`, `.archive-row`.

**Visual reference:** [C10 chat list](../component-references/c10-chat-list/README.md): the mockup list, night theme row states, the search pill and the pill geometry, with computed contrast for text and badges.

**Depends on:** [shell layout](2026-10-29-shell-layout.md), [surface roles](2026-10-29-surface-roles.md) (C4 made the unselected row background transparent while material is active).

## Global Constraints

- All [ground rules](README.md#ground-rules).
- Row pill at 100 % scale: margins `6, 1, 2, 1` (left, top, right, bottom) inside the row rect, radius `10`.
- Hover fill: primary text color at alpha `0.06` light / `0.07` dark.
- Active (open chat) row under Soft Panels: the opaque light selected pill `Ui::Material::SelectedFill()` (C17) with the row's normal text, badge and icon colors, the exploration's light selection (user decision 2026-10-31). Without Soft Panels it keeps `dialogsBgActive` and its `*Active` colors.
- Search pill: height `34`, margins `10, 6, 8, 8`, radius `9`, Bar role, border `Border(Surface::Bar)`.
- Row height, avatar size, fonts, badges sizes (`dialogsUnreadHeight` 19 px) stay Telegram's.
- Every behavior stays: click, middle click, context menu, drag-to-pin, swipe actions, keyboard navigation, topics expansion, archive collapse, stories strip, search scopes and filters.

## Review Focus

- Drag to reorder pinned chats: the dragged row's pill moves with it and the empty slot shows no stale pill. Pinned by Task 1 Step 4.
- The press ripple: it must be clipped to the pill, not the square row. Pinned by Task 1 Step 2.
- Touchpad swipe quick actions (archive, mute, read): the action fill stays a full-width square under the sliding row. Pinned by Task 1 Step 4.
- Cached rows with emoji status badges: the badge cut-out must be transparent over material, not a `dialogsBg` square. Pinned by Task 3 Step 1.
- Narrow (collapsed) chats list showing only avatars: pills center on the avatar. Pinned by Task 1 Step 3.

### Task 1: Rounded row highlights

**Files:**
- Modify: `Telegram/SourceFiles/dialogs/dialogs.style`
- Modify: `Telegram/SourceFiles/dialogs/ui/dialogs_layout.h`, `dialogs_layout.cpp`
- Modify: `Telegram/SourceFiles/dialogs/dialogs_inner_widget.cpp`

**Interfaces:**
- Produces style values: `dialogsSoftPanelsRowMargins: margins(6px, 1px, 2px, 1px)`, `dialogsSoftPanelsRowRadius: 10px`, `dialogsSoftPanelsNarrowRowMargins: margins(4px, 1px, 4px, 1px)`.
- Produces, in `Dialogs::Ui::PaintContext` (`dialogs_layout.h`): `bool softActive = false;` — the open chat under Soft Panels; it is painted with `active` false and `selected` true, so every text and badge takes its normal colors.
- Produces, file-local in `dialogs_layout.cpp`: `void PaintRowBackground(QPainter &p, const QRect &geometry, const QBrush &bg, const PaintContext &context);` — square `fillRect` without Soft Panels; with Soft Panels a rounded rect inset by the margins (narrow margins when `context.narrow`), filled with `SelectedFill()` when `context.softActive`, skipping fully transparent brushes; hover (`context.selected && !context.active`) uses the hover fill instead of `st::dialogsBgOver` while material is active.

- [ ] **Step 1: Add the style values and `PaintRowBackground`**

- [ ] **Step 2: Use it in `PaintRow`**

Replace `p.fillRect(geometry, bg)` with `PaintRowBackground(p, geometry, bg, context)`. In `dialogs_inner_widget.cpp`, wherever a context sets `.active` for the open chat (chats, topics, search results), under Soft Panels set `.softActive` and pass `.active = false, .selected = true` instead. Before `row->paintRipple(...)`, when `SoftPanels()`, set the painter clip to the same rounded path and restore it after.

- [ ] **Step 3: Use it in the other row painters**

Apply the same replacement to the background fill in `PaintCollapsedRow` and to any other `fillRect` of `context.currentBg`, `st::dialogsBgOver` or `st::dialogsBgActive` in `dialogs_layout.cpp`. Search results, topic rows and the "search in" chips use these painters; check each in Step 4.
