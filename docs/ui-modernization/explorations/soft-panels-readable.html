Telegram Desktop · design preview
  • Readable material: the folder rail and chat list share one panel fill, and the conversation canvas is denser, so small text reaches 4.5:1 on every test wallpaper. Text colors are slightly stronger.
  • Telegram behavior: the main menu returns at the top of the rail, folders show unread counts, muted chats use grey badges plus a muted icon, and the composer switches between voice recording and send.
  • Sizes: Telegram's style values (13 px text, 46 px avatars, 62 px rows, 19 px badges) scaled by the interface scale; 125% is close to the approved sizes.
  • Chat wallpaper: a chat wallpaper fills the message area below the header, while the header, pinned bar and bubbles keep their own fills.
